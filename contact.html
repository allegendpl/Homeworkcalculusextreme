Let’s make the next round better.

Broken game? A keyboard that won’t cooperate? Tell the repository owner through the project issue tracker. This static site has no form backend, and we won’t pretend to send a message it cannot deliver.

Report a problem

Include the game title or URL, your browser and device, the steps to reproduce, and what you expected to happen. A screenshot helps. Never include passwords, school credentials, API keys, or other private data.

Open a GitHub issue ↗

If issues are disabled, the repository owner needs to enable them in GitHub Settings → General → Features. A GitHub account is required to file an issue.

Rights holders

For copyright or permission concerns, follow the removal request instructions. Ask for a private channel before sharing personal documents.

Want to contribute?

Propose an original or permissively licensed game in the repository. Include source, author, license evidence, thumbnail rights, and embed permission. An embed URL by itself is not permission.
